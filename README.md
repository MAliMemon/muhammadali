# 🌐 Student Portfolio Website

This is a simple, responsive **portfolio website** created during my **second semester** as part of my personal learning journey. The site showcases my early skills in **HTML**, **CSS**, and basic **JavaScript**. It is built with the goal of introducing myself, sharing my resume, and providing easy ways to connect.

---

## 🎯 Purpose

This project was developed as a personal portfolio to:
- Showcase basic web development skills
- Practice layout, styling, and responsive design
- Experiment with JavaScript-based navigation
- Serve as a foundation for future improvements

---

## 🛠️ Technologies Used

- **HTML5** – structure and content
- **CSS3** – styling and layout
- **JavaScript** – simple section toggling (SPA-like experience)

---

## ✨ Features

- 🔸 Clean dark-mode aesthetic
- 🔸 Navigation without page reloads
- 🔸 "About Me" section with resume download
- 🔸 Contact section with links to LinkedIn, Email, and GitHub
- 🔸 Profile image with hover animation
